# SiliconForge interactive autonomy simulator

Open SiliconForge_Autonomy_Simulator_v2.html locally in Chrome/Edge. Free mode accepts events while idle or running; it visualizes route, owner state, peer messages, evidence and no-progress guards. This is a rules-based mock, not proof of Codex, EDA or production integration.

Use it to validate architecture expectations, then replace rules with durable runtime and real independent EDA events. Do not count its visual green indicators for A2/A3/A4 engineering signoff.
